# Mandatory Rule: Always Read & Update README.md

1. **Before starting any task or writing code**:
   - Always read `README.md` in the project root first to ground all decisions in the latest project context, architecture, dependencies, and feature specifications.

2. **After adding or modifying any code or feature**:
   - Always update `README.md` immediately whenever any code, feature, route, service, component, database schema, or configuration is added or modified.
   - Keep the project structure, features list, API endpoints, setup instructions, and architecture diagrams completely synchronized with the live codebase in full detail.
