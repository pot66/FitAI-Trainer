# FitAI Trainer

AI-powered fitness assistant platform.

## Features

- User Registration & Login
- User Profile
- BMI Calculation
- AI Fitness Chat
- Voice Chat
- Exercise Pose Detection
- Exercise Repetition Counting
- Exercise Posture Analysis
- Workout History
- Chat History
- AI Exercise Recommendation

## Architecture

- Frontend: React
- Backend: Node.js + Express
- AI Service: Python
- Computer Vision: MediaPipe
- Database: PostgreSQL
- Cache: Redis
- Containerization: Docker
